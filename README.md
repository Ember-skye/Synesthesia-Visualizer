# Synesthesia-Visualizer
# VOID // SYNESTHESIA

A futuristic browser-based audio visualizer built with pure HTML, CSS, and JavaScript.

## ✨ Features

* Real-time audio visualization using Web Audio API
* Multiple visualization modes:

  * Void
  * Wave
  * Bars
  * Radial
  * Reactor
  * Nebula
  * Quantum Fold
  * Gravity Torus
  * Singularity
  * Synth Horizon
  * Liquid Mandala
* Drag & drop music upload
* Audio controls (Play / Pause / Stop)
* Interactive progress bar
* Futuristic cyberpunk UI
* Dynamic glow and glitch effects
* Responsive fullscreen canvas rendering

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Canvas API
* Web Audio API

---

## 📂 Supported Audio Formats

* MP3
* WAV
* FLAC
* OGG

---

## 🚀 How to Run

1. Download the project files
2. Open the HTML file in your browser
3. Upload an audio file
4. Enjoy the visual experience
